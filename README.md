# manty-waf

웹 애플리케이션 앞에 두어 HTTP 트래픽을 검사하고, 공격과 남용을 걸러 내는 WAF(Web Application Firewall)다.
아래는 제품이 갖춰야 할 기능 목록이다. 구현 순서와 범위는 아직 정하지 않았다.

## 배포와 트래픽 경로

- 리버스 프록시로 인라인 배치한다.
- 투명 브리지, 호스트 에이전트, 쿠버네티스 Ingress·사이드카처럼 배치 방식을 고를 수 있다.
- HTTP/1.1, HTTP/2, HTTP/3를 받는다.
- TLS 종단, TLS 패스스루, 업스트림 mTLS를 지원한다.
- WebSocket과 gRPC 스트림을 검사 대상에 포함한다.
- 요청과 응답을 모두 본다. 업로드 본문, 청크 전송, 압축 본문을 풀어 검사한다.
- 검사 한도를 둔다. 본문 크기, 헤더 수, 헤더 길이, 파라미터 수를 넘기면 거절하거나 잘라 검사한다.

## 프로토콜 검증

- HTTP 문법과 비정상 요청을 거른다. 잘못된 메서드, 중복 헤더, 스머글링에 쓰이는 분할을 포함한다.
- Host, 경로, 쿼리, 쿠키, Content-Type이 정책과 맞는지 확인한다.
- 허용 메서드와 허용 Content-Type을 애플리케이션마다 둔다.
- 요청 크기, 연결 시간, 헤더 읽기 시간, 본문 읽기 시간에 상한을 둔다.

## 시그니처 탐지

- SQL 인젝션, XSS, 명령 인젝션, 코드 인젝션, 경로 탐색, 파일 포함, SSRF, XXE, SSTI, LDAP·NoSQL 인젝션을 탐지한다.
- OWASP CRS처럼 공개 규칙 집합을 불러오고, 사이트 전용 커스텀 규칙을 추가한다.
- 규칙은 헤더, 쿠키, 쿼리, 본문, 업로드 파일명, JSON·XML·GraphQL 필드에 선택적으로 건다.
- 탐지 전용(detect)과 차단(block)을 규칙·경로·애플리케이션 단위로 나눈다.
- 오탐이 난 규칙을 경로, 파라미터, 소스 IP 기준으로 예외 처리한다.
- 알려진 CVE에 대해 애플리케이션을 패치하기 전까지 가상 패치 규칙을 올린다.

## 허용 목록 보안

- 차단 목록과 함께, 허용된 URL·메서드·파라미터·타입만 통과시키는 포지티브 모델을 둔다.
- OpenAPI, gRPC proto, GraphQL 스키마로 요청 형태를 검증한다.
- 학습 모드에서 정상 트래픽을 보고 허용 목록 초안을 만든다. 운영자가 검토한 뒤 정책으로 승격한다.

## 파일 업로드

- 확장자, MIME, 매직 바이트가 서로 맞는지 본다.
- 실행 가능 파일, 웹셸에 자주 쓰이는 확장자, 이중 확장자를 막는다.
- 파일 크기와 개수 상한을 둔다.
- 악성코드 검사 엔진이 있으면 연동하고, 없으면 그 자리는 비워 둔다.

## 봇과 계정 남용

- 알려진 좋은 봇(검색엔진 등)과 나쁜 봇, 위장 User-Agent를 구분한다.
- IP, 세션, 계정, API 키 기준으로 요청 속도를 제한한다.
- 로그인, 비밀번호 재설정, OTP처럼 민감한 경로에 더 빡센 한도를 둔다.
- 크리덴셜 스터핑과 브루트포스를 탐지한다. 짧은 시간에 많은 계정, 또는 한 계정에 많은 실패가 대상이다.
- 의심 트래픽에 JS 챌린지, 인터스티셜, CAPTCHA를 건다.
- 스크래핑과 콘텐츠 핫링크를 경로 정책으로 막는다.

## 가용성

- 애플리케이션 계층 플러드(HTTP flood)를 완화한다.
- Slowloris, slow POST처럼 연결을 오래 붙잡는 공격을 끊는다.
- 동시 연결 수, 소스별 신규 연결 속도, 업스트림 동시성에 상한을 둔다.
- 백엔드가 아프면 새 요청을 거절하거나 대기열에 넣어 업스트림을 보호한다.

## 접근 제어

- IP, CIDR, ASN 허용·차단 목록을 둔다.
- 국가·지역 단위로 허용하거나 차단한다.
- IP 평판과 위협 인텔리전스 피드를 반영한다. 피드가 없어도 수동 목록으로 동작한다.
- Tor 출구, 호스팅 대역, 익명 프록시처럼 출처 유형으로 정책을 나눈다.
- User-Agent, Referer, 커스텀 헤더로 보조 조건을 건다.
- 관리 포트와 헬스 체크는 데이터 플레인 정책과 분리한다.

## API 보안

- API를 호스트·경로 기준으로 발견하고 목록으로 남긴다.
- OpenAPI에 없는 경로·파라미터·타입을 탐지하거나 차단한다.
- JWT 서명, 만료, issuer, audience를 검사한다. 비밀키는 WAF 밖에 둔다.
- GraphQL은 쿼리 깊이, 복잡도, 인트로스펙션, 배치 쿼리 수를 제한한다.
- gRPC는 메서드 허용 목록과 메시지 크기 상한을 둔다.
- API 키와 호출량 쿼터를 경로별로 적용한다.

## 정책 운영

- 정책은 애플리케이션(호스트 또는 경로 접두사) 단위로 둔다.
- 전역 정책 위에 애플리케이션 정책을 덮어쓴다.
- 정책을 코드로 저장하고, 버전을 남기며, 이전 버전으로 되돌린다.
- 규칙을 내리지 않고 다시 읽어 적용한다.
- 변경은 감사 로그에 누가, 언제, 무엇을 바꿨는지 남긴다.
- 멀티테넌트에서 테넌트 정책과 데이터가 섞이지 않게 격리한다.

## 로그와 대응

- 보안 이벤트에 시간, 액션(허용·탐지·차단·챌린지), 규칙 ID, 호스트, 경로, 소스 IP, 매칭된 위치를 남긴다.
- 로그에서 비밀번호, 토큰, 카드번호, 세션 쿠키를 마스킹한다.
- 원문 요청 저장은 기본 끄고, 사건 단위로 짧은 시간만 켠다.
- 메트릭으로 허용·차단 수, 지연, 규칙별 히트, 업스트림 오류를 뽑는다.
- 대시보드에서 최근 공격, 상위 규칙, 상위 소스, 오탐 후보를 본다.
- 웹훅, syslog, SIEM으로 이벤트를 보낸다.
- 차단된 요청에 일관된 상태 코드와 요청 ID를 돌려 주고, 공격자에게 규칙 내부를 드러내지 않는다.

## 운영

- 무중단으로 스케일 아웃하고, 인스턴스 장애 시 다른 인스턴스가 받는다.
- 설정과 규칙은 인스턴스 밖에 둔다.
- 프로메테우스 호환 메트릭과 헬스·레디니스 엔드포인트를 제공한다.
- 컨테이너 이미지와 쿠버네티스 매니페스트로 배포한다.
- 검사 추가로 붙는 지연의 목표치를 경로별로 측정한다.
